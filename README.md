# Sorcerer Synthesis Patcher

Synthesis patcher for [Sorcerer - A Staff and Scroll Overhaul](https://www.nexusmods.com/skyrimspecialedition/mods/95196).

[![Build](https://github.com/kundrun/Sorcerer-Patcher-Reborn/actions/workflows/build.yml/badge.svg)](https://github.com/kundrun/Sorcerer-Patcher-Reborn/actions/workflows/build.yml)

---

To get started with this patcher, head over to the [Synthesis wiki](https://github.com/Mutagen-Modding/Synthesis/wiki). Follow
the instructions to install the main Synthesis program and any patchers for it (such as this one).
